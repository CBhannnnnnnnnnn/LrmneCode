# 用户指南

面向使用 LrmneCode 的开发者。安装、配置、命令与常见工作流都在这里。

---

## 1. 安装

需要 **Python 3.11+**。推荐在虚拟环境里安装：

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # Windows
# source .venv/bin/activate          # macOS / Linux
```

从 PyPI 安装：

```bash
pip install lrmne-code
```

从源码安装（克隆仓库后，在仓库根目录执行）：

```bash
pip install .
```

也可以直接从 Git 仓库安装：

```bash
pip install "git+https://github.com/CBhannnnnnnnnnn/LrmneCode.git"
```

安装后得到 `lrmnecode` 命令；验证：

```bash
lrmnecode --version
```

---

## 2. 首次配置

LrmneCode 需要模型提供方、API Key 和模型名。

**方式 A：应用内配置（推荐）**

按 `F2` 或输入 `/model` 打开模型配置窗口，在左侧选提供方，右侧填凭证字段与模型名，点「保存」。

- 支持：Anthropic、OpenAI、DashScope、DeepSeek、Gemini、Moonshot、xAI、Ollama。
- 已经配过之后**只想换模型名**，不必重填 API Key：留空即沿用已配置的凭证。

**方式 B：编辑配置文件**

把 `settings.example.json` 复制到 `~/.lrmnecode/settings.json`
（Windows：`C:\Users\<你的用户名>\.lrmnecode\settings.json`）：

```json
{
  "model": {
    "provider_type": "openai_credential",
    "credential": {
      "api_key": "sk-你的密钥",
      "base_url": "https://api.openai.com/v1"
    },
    "model": "gpt-4o"
  }
}
```

`provider_type` 可选值同上；不同提供方的 `credential` 字段（如 `base_url`）以提供方要求为准。

> 配置写错时，应用不会静默吞掉：它会在状态栏 / 浮窗里提示「配置有问题」及原因。

## 3. 启动与界面

在**你要操作的项目目录**下启动：

```bash
lrmnecode
```

界面自上而下：

- **标题栏**：产品名与副标题。
- **转录区**（左侧主区）：用户消息、助手回复、思考块、工具调用块、通知行。
- **右侧栏**：这次会话的量化信息——上下文构成、token 用量与吞吐、缓存命中、思考 / 权限档位、工作目录、会话号。
- **状态栏**：运行状态、模型、待处理审批数、上下文压力。
- **输入框**：`/` 呼出命令，`@` 引用文件，`Esc` 暂停。
- **底栏**：快捷键提示。

启动时会自动创建新会话并拉取配置。后端在一个独立子进程里运行；若它崩溃，界面会提示
「后端进程已退出」并附上错误尾部。

---

## 4. 输入与快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 发送消息 |
| `Tab` | 补全当前候选（命令 / 引用） |
| `Esc` | 收起面板 → 拒绝审批 → 暂停在途对话（按当前有什么依次处理） |
| `↑` `↓` | 在候选面板中导航 |
| `F2` | 打开模型配置窗口 |
| `F3` | 打开会话切换窗口 |
| `Ctrl+Q` | 退出 |

普通文本回车即发送。以 `/` 开头会被当作**斜杠命令**（不发送给模型）；正文里的 `@` 会触发文件引用。

---

## 5. 斜杠命令

输入 `/` 会弹出命令面板（`↑↓` 选、`Enter` 执行、`Tab` 补全）。命令本身**不带参数**：
需要选值时会弹出卡片让你挑。

| 命令 | 别名 | 说明 |
|---|---|---|
| `/help` | `/?` | 显示所有可用命令 |
| `/model` | `/login` | 打开模型配置窗口 |
| `/new` | `/new-chat` | 开新对话 |
| `/sessions` | `/resume` | 切换会话 / 载入磁盘存档 |
| `/clear` | `/reset` | 清空当前会话的显示 |
| `/thinking` | | 选择思考级别 |
| `/permission` | `/perm` | 选择权限模式 |
| `/context` | | 选择上下文窗口大小 |
| `/cwd` | `/cd` | 切换工作目录 |
| `/attach` | | 附加文件到下一条消息 |
| `/attachments` | `/attlist` | 查看待发送附件 |
| `/skills` | | 浏览并执行 skill |
| `/mcp` | | 查看已连接的 MCP 服务器 |
| `/diff` | | 查看某一轮的文件改动 |
| `/undo` | | 撤销某一轮的文件修改 |
| `/quit` | `/exit` | 退出 |

### 命令要点

- **`/thinking`**：`off`（不思考，最快）、`low`、`medium`（默认）、`high`（深思考，最慢）。
- **`/context`**：上下文窗口档位，`200K`（日常够用）、`400K`（长文件与多轮）、`1M`（超大仓库，最耗额度）。
- **`/cwd`**：输入绝对路径切换工作目录；会重建工作区，磁盘存档保留。
- **`/attach`**：把文件读成附件随下一条消息发送（适合图片、PDF 等模型不能直接读的二进制）；
  正文里的 `@路径` 则不读文件，由模型自己用工具去取。
- **`/diff` / `/undo`**：见第 9 节。

---

## 6. 引用文件与 Skill：`@`

在正文里输入 `@` 会弹出候选：

- **文件**：`@backend/adapter/chat.py`，插入后模型知道要看这个文件，内容由它自己去读。
- **目录**：`@backend/adapter/`，回车可继续往下钻一层。
- **Skill**：`@review`，把某个 skill 的名字点出来（skill 是说明文档，由模型自行阅读并执行）。

规律：

- `@` 后什么都没打 → 列当前这一层（目录在前）。
- `@` 后打了字 → 在当前作用域之下递归搜索，按文件名前缀优先排序。
- 中文标点会结束这个引用词（`@a.py，然后…` 只引用 `a.py`）。

正文里的 `@引用` 会带底色高亮，方便你一眼看出引用了哪些文件。

## 7. 会话管理

- 每个会话有一个会话号（形如 `c-1a2b3c4d`）。
- **本进程会话**：`/new` 开新对话，`F3` 或 `/sessions` 打开会话切换窗口，在「本进程」组里 `Enter` 切前台
  （草稿与滚动位置都还在）。
- **磁盘存档**：切换窗口下半列出历史存档，`Enter` 会把它载入成**新会话**（不会覆盖你正开着的会话）。
- **关闭本进程会话**：在会话窗口里按 `x`（磁盘存档不删）。
- **删除磁盘存档**：按 `d`，需要**再按一次 `d`** 确认（不可恢复）。
- 会话状态在每个回合结束后自动落盘，退出后也能续上。

---

## 8. 权限与审批

用 `/permission` 切换权限模式：

| 模式 | 说明 |
|---|---|
| `default` | 每次改动都询问 |
| `accept_edits` | 工作区内编辑自动允许 |
| `explore` | 只读，改动一律拒绝 |
| `bypass` | 跳过安全检查，谨慎使用 |
| `dont_ask` | 不询问，待处理一律拒绝 |

当模型要执行敏感操作（如写文件、跑命令）时，会弹出**审批面板**显示要做什么。你可以：

- **允许**这次操作；
- **始终允许**这类操作（`always`）；
- **拒绝**。

按 `Esc` 可以拒绝当前待处理的审批。审批期间工具耗时不计入统计。

---

## 9. 文件改动与撤销

每轮对话**开始前**，LrmneCode 会给工作区做一次快照。

- `/diff`：选择某一轮，查看该轮相对快照的文件改动（unified diff）。
- `/undo`：选择某一轮，把该轮快照写回磁盘，整体回滚。

限制：

- 只快照能被 UTF-8 解码的文本文件；二进制文件不纳入。
- 会跳过 `.git`、`.lrmnecode`、`__pycache__`、`node_modules`、`.venv` 等目录。
- 每个会话最多保留最近 **20** 轮快照，更旧的会被丢弃。

---

## 10. Skills 与 MCP

- **Skills**：项目级能力说明放在 `<项目根>/.lrmnecode/skills/`。用 `/skills` 浏览并执行，
  或在正文里用 `@skill名` 引用。
- **MCP**：Model Context Protocol 服务器用于接入外部工具。用 `/mcp` 查看已连接的服务器，
  配置放在 `<项目根>/.lrmnecode/mcp/`。

两者都在启动 / 切换工作区时由后端加载。

---

## 11. 配置文件与目录

**全局（跨项目）**：`~/.lrmnecode/settings.json`

```json
{
  "model": {
    "provider_type": "openai_credential",
    "credential": { "api_key": "sk-...", "base_url": "https://api.openai.com/v1" },
    "model": "gpt-4o"
  }
}
```

**项目级**：`<项目根>/.lrmnecode/`

```
.lrmnecode/
├── sessions/     # 会话状态存档
├── snapshots/    # 每轮快照（供 diff / undo）
├── skills/       # 项目级 Skills
└── mcp/          # MCP 服务器配置
```

模型凭证属于你个人，所以放在用户主目录；会话与快照属于具体项目，所以放在项目下的 `.lrmnecode/`。
这个目录是产品元数据，不属于你的应用代码，也不会被快照纳入。

## 12. 常见问题

**启动后提示模型未配置？**
先按 `F2` 配好提供方、API Key 与模型名，或检查 `~/.lrmnecode/settings.json` 是否合法。

**界面一直「运行中」，什么都不动了？**
多半是后端在这一轮卡住或崩溃。按 `Esc` 尝试暂停；若状态栏提示「后端进程已退出」，
查看转录区末尾的错误尾部（stderr）。也可以 `Ctrl+Q` 退出后重启。

**`@` 或 `/` 没反应？**
确认光标情境：命令只在整段正文以 `/` 开头且没有空格时触发；`@` 要在词首（前面是空白或行首）。

**改了代码但行为没变？**
若以 `pip install .` 安装，需要重装；开发请用 `pip install -e ".[dev]"`。

**想换项目目录？**
用 `/cwd` 输入新的绝对路径，或在新目录下重新启动。切换工作目录会重建工作区，旧目录的磁盘存档仍在原处。
